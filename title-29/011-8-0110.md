# 29-11.8-110. License fees.
(1) The following license fees shall be paid to the local licensing authority annually in advance:
(a) For the issuance of a new escort bureau license, an amount to be set by the local licensing authority, but in no event to exceed five thousand dollars;
(b) For each renewal of an escort bureau license, an amount to be set by the local licensing authority, but in no event to exceed five thousand dollars;
(c) For the issuance of a new escort or escort bureau runner license, an amount to be set by the local licensing authority, but in no event to exceed five hundred dollars;
(d) For each renewal of an escort or escort bureau runner license, an amount to be set by the local licensing authority, but in no event to exceed two hundred fifty dollars.
