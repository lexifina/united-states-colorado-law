# 18-8-801. Definitions.
As used in this part 8, unless the context otherwise requires:
(1) "Emergency medical service provider" has the same meaning as set forth in section 25-3.5-103 (8).
(2) "Materially false statement" has the meaning set out in section 18-8-501 (1).
(3) "Peace officer" has the meaning set out in section 16-2.5-101.
